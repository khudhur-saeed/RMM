# Frontend Web Application

## Overview
Vite-powered React single page application (SPA) control plane client for Tactical RMM. Configures Vite tooling, development reverse proxy for REST and WebSocket APIs, ESLint rules, HTML entry template, and project dependency tree.

## Subdirectories & Boundaries
- **[src](./src/README.md)**: Core application shell, top-level routing, navigation, and UI component views

## Verification
- Run: `npm run build`
